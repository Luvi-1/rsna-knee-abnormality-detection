# Visual QA handbook

## Purpose

This document defines the minimum visual checks a human reviewer should perform
before approving any model output for promotion. It covers synthetic fixtures
now and real DICOM slices after the data gate opens.

## Pre-flight (synthetic only)

- Confirm all test images are generated by seeded numpy RNG; no real pixels.
- Verify the notebook prints aggregate values only (loss, shape tuple).
- Check that no raw tensor data appears in stdout or saved artifacts.

## Real-data QA checklist (requires authenticated access)

For each of the 12 targets, inspect at least 3 positive and 3 negative examples:

1. Does Grad-CAM attention overlap with the anatomical structure of interest?
2. Are there any slices where the model attends to text overlays or scanner
   artifacts rather than tissue?
3. For bilateral structures (MCL/LCL, medial/lateral meniscus), does the model
   attend to the correct side?
4. For OA targets, does attention cover joint space and osteophyte regions?
5. Is any slice producing extreme confidence (>0.99) on an ambiguous finding?

## Red flags requiring escalation to human review

- Model confidence is high on a slice with no visible relevant anatomy.
- Attention pattern changes drastically between adjacent slices.
- A target that was negative in weak labels receives high positive probability.
- Any evidence of patient-identifiable information in model input or output.

## Escalation path

Any red flag triggers mandatory human review. The reviewer records their
decision in the annotation database with reviewer_id and created_utc. No model
output may be promoted while any red flag remains unresolved.
