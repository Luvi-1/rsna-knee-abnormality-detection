# Experiment Contract

## Before run

- Experiment ID:
- Hypothesis:
- Primary change:
- Frozen controls:
- Data-manifest version:
- Label/fold/preprocessing versions:
- Model, loss, augmentation, seed:
- Compute estimate:
- Expected information gain:
- Promotion criterion:
- Kill criterion:

## After run

- Code commit and config hash:
- Actual runtime/cost:
- Macro OOF AUC and 12 label AUCs:
- Bootstrap intervals:
- Manual report/MRI validation:
- Domain-shift results:
- Failure modes and prediction correlations:
- Hypothesis supported:
- Decision: keep / reject / revise / ensemble-only
