## Authoritative clarification added

The Competition Host's `Use of Commercially Hosted LLMs` topic, posted on 2026-08-09, states that
commercially hosted LLMs and external inference services may be used when the service and method
comply with all Competition Rules and service terms, including reasonable-access and minimal-cost
requirements. It also states that submitting competition report text for computational processing
is not, by itself, prohibited private sharing.

This source was already public before the immediately previous refresh but was not recorded there;
the correction is newly discovered evidence, not evidence that the Host changed the rule today.
The repository's operating boundary is intentionally narrower: only recognized members of the same
official Kaggle team may receive private competition code or data, and no raw DICOM pixels,
radiology reports, patient-level metadata, identifiers, private competition code or data, or
private artifacts may be sent to an external LLM, API, or service. No private content was provided
to any external service during this audit.
